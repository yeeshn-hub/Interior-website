# 인테리어 추천 사이트 — 워크플로 & 테무 제휴 가이드

> 개발 계획서의 보충 문서. 상품 데이터가 어디서 와서 어떻게 사용자에게 닿는지, 테무 제휴 링크를 어떻게 만드는지 정리한다.
> 작성일: 2026-11-15

---

## 1. 핵심 요약

- 테무에는 제휴 회원이 상품 목록을 받아올 수 있는 **공개 API가 없다.** 공식 API는 판매자가 자기 상점의 상품·주문·배송을 관리하는 용도뿐이다.
- 그래서 상품 데이터는 **사람이 직접 고르고(큐레이션) 정리한다.**
- 데이터 흐름: **사람이 큐레이션 → 시트 → `products.json`(MVP) / Supabase(2단계) → 웹페이지**
- 테무와 자동으로 연결되는 지점은 **사용자가 상품을 클릭해 테무로 이동하는 순간** 하나뿐이다.

---

## 2. 전체 워크플로

```
[운영자 · 미리 준비]
 테무 제휴 대시보드 ──▶ 구글 시트 ──▶ products.json (2단계: Supabase)
   (제휴 링크 생성)     (콘셉트·치수 태그)          │
                                                 │ 상품 조회
[사용자 · 사이트 방문]                              ▼
 가구·방 입력 ──▶ 배치 엔진 ──▶ 배치안 3~4개 + 상품 매칭
 (가구 개수, 방 치수) (브라우저에서 계산)          │
                                                 ▼
 수수료 정산 ◀── 테무에서 구매 ◀── 상품 클릭 (/go 리다이렉트·기록)
 (30~60일 후)    (제휴 링크 경유)

 ↻ 클릭 기록을 보고 시트의 상품을 교체·보강
```

### 운영자 쪽 (미리 준비)

1. **테무 제휴 대시보드**: 소개할 상품의 제휴 링크를 만든다.
2. **구글 시트**: 상품 하나당 한 행씩 정보와 태그를 입력한다.
3. **변환**: 시트를 CSV로 내보내고 스크립트로 `products.json`을 만든다. 2단계에서는 같은 CSV를 Supabase로 가져온다.

### 사용자 쪽 (사이트 방문)

1. 가구 목록과 방 치수(문·창문 위치 포함)를 입력한다.
2. 배치 엔진이 **브라우저 안에서** 배치안 3~4개를 계산한다.
3. 배치안마다 콘셉트·빈 공간·가구 구성에 맞는 상품을 `products.json`에서 골라 보여준다.
4. 상품을 클릭하면 `/go/:id` 서버리스 함수가 클릭을 기록하고 제휴 링크로 보낸다.
5. 사용자가 테무에서 구매하면 수수료가 쌓이고, 반품 기간이 지난 뒤 지급된다.

> 서버가 하는 일은 `/go` 리다이렉트 함수 하나뿐이다. 나머지는 정적 사이트 + 브라우저 계산.

## 3. 상품 데이터 구조

### Supabase / products.json 구조

| 단계 | 저장 위치 | 언제 |
| --- | --- | --- |
| MVP | `products.json` (사이트와 함께 배포) | 상품 50~100개, 수정 시 재배포해도 괜찮을 때 |
| 2단계 | Supabase `products` 테이블 | 관리자 화면, 계정·즐겨찾기 기능이 필요할 때 |

웹페이지는 MVP에서 `products.json`을 직접 읽고, 2단계부터는 `supabase-js`로 `products` 테이블을 조회한다. (예: `concepts`에 `gaming`이 들어간 조명 상품)

### 시트 컬럼 (= `Product` 타입)

| 컬럼 | 예시 | 비고 |
| --- | --- | --- |
| `id` | `601099651743804` | 상품 URL의 `goods_id` 값 |
| `title` | LED 스트립 조명 5m | |
| `image` | 이미지 URL | |
| `affiliateUrl` | 제휴 대시보드에서 변환한 링크 | **일반 URL 금지** |
| `category` | lighting / rug / storage / gaming ... | |
| `concepts` | focus, gaming | 어울리는 배치 콘셉트 (여러 개 가능) |
| `minFreeArea` | 40 | 필요한 빈 공간(cm), 선택 |
| `priceBand` | low / mid / high | 가격은 변동이 커서 대략적인 가격대만 |

### 작업량 감각

- 필요한 건 테무 전체가 아니라 **카테고리 10개 × 5~10개 = 50~100개** 정도.
- 상품 하나에 2~3분이면 100개를 하루 이틀 저녁에 끝낼 수 있다.
- 자동화가 어려운 건 **콘셉트 태그와 필요 공간** 입력이고, 상품 매칭이 이 태그로 돌아가므로 여기에 시간을 쓴다.

### 작업 줄이는 방법

1. **시트 → JSON 변환 스크립트**: JSON을 손으로 쓰지 않는다.
2. **북마클릿/작은 확장 프로그램**: 지금 열어 둔 상품 페이지의 제목·이미지 URL·상품 ID를 복사. 사이트 전체를 긁는 스크래핑은 약관 위반과 차단 위험이 있으므로 하지 않는다. 상품 이미지·정보 사용 범위는 제휴 약관에서 확인한다.
3. **대시보드 기능 확인**: 링크 일괄 생성, 추천 상품 목록, 제휴 네트워크의 상품 피드가 있는지 가입 후 확인한다.

## 4. 테무 제휴 링크란?

**내 추천 코드가 붙은 테무 상품 주소**다.

| | 일반 링크 | 제휴 링크 |
| --- | --- | --- |
| 이동하는 곳 | 상품 페이지 | 같은 상품 페이지 |
| 사용자에게 보이는 가격 | 같음 | 같음 |
| 판매 추적 | 안 됨 | 됨 (내 계정으로 기록) |
| 내 수익 | 0원 | 구매 시 수수료 |

- 사이트의 "테무에서 보기" 버튼에는 **반드시 제휴 링크**를 넣는다. 일반 URL을 넣으면 아무리 팔려도 수익이 0원이다.
- 링크 옆에 "이 링크를 통해 구매하면 수수료를 받습니다" 같은 고지 문구를 항상 보이게 둔다.

### 알아둘 조건 (가입 전 공식 페이지에서 재확인)

- 수수료는 카테고리별로 대략 5~20%. 홈·가든 8~12%, 전자제품 5~8% 수준.
- 신규 사용자가 앱 설치 후 첫 주문하면 별도 보너스.
- 수익은 반품 기간이 끝난 뒤 지급(판매 후 30~60일). 반품·취소된 주문은 차감.
- 승인까지 보통 3~7 영업일. 만 18세 이상, 지역별로 프로그램이 다르므로 대상 시장(한국/캐나다)을 먼저 정한다.

## 5. 제휴 링크 만드는 법

> 제3자 가이드 기준. 지역·시점에 따라 버튼 이름과 위치가 다를 수 있다.

### 0단계: 가입 승인

- 제휴 프로그램에 가입하고 승인을 받으면 확인 이메일과 함께 대시보드에 들어갈 수 있다.
- 이후 테무 검색창에 **"affiliate"**를 검색하면 제휴 페이지가 열린다.

### 방법 1: 상품 페이지 URL 변환 (추천)

1. PC에서 테무에 들어가 상품을 검색하고, 이미지를 눌러 상세 페이지를 연다.
2. 오른쪽 위 **공유 아이콘 → 링크 아이콘**으로 상품 URL을 복사한다. (아직 일반 링크)
3. 제휴 페이지 → **Hot Items** 탭 → **Convert Link** 버튼.
4. URL을 붙여넣고 **Get Item Link** 클릭.
5. 홍보 문구 말고 **제휴 링크만** 복사한다.

### 방법 2: 주소창 URL을 딥링크로 변환

- 상세 페이지의 브라우저 주소창 URL을 복사 → 제휴 페이지의 딥링크 생성 도구로 변환. 결과는 방법 1과 같다.

### 방법 3: Hot Items에서 바로 공유 / 상품 ID 검색

- Hot Items 목록에서 상품 옆 **Share**를 누르면 제휴 링크가 복사된다. 테무가 밀어주는 상품 위주라 인테리어 소품 찾기엔 불편할 수 있다.
- 상품 ID를 제휴 페이지 검색창에 붙여넣으면 그 상품이 나오고, **Share**로 링크를 복사할 수 있다.

### 이 프로젝트용 작업 순서

1. 카테고리별 후보 상품을 탭으로 열어 둔다 (조명, 러그, 수납, 커튼, 게이밍 의자, 데스크 소품 등).
2. 상품마다 방법 1로 제휴 링크를 만든다.
3. 시트에 한 행씩 채운다 (3장의 컬럼).
4. 처음 몇 개는 **시크릿 창**에서 링크를 열어 올바른 상품으로 가는지 확인한다.
5. 출시 후에는 제휴 대시보드의 클릭·전환·수익과 사이트의 `/go` 클릭 기록을 비교해, 어떤 콘셉트가 실제 구매로 이어지는지 확인하고 상품을 교체한다.
